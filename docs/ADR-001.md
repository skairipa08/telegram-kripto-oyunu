# ADR 001 Mimari ve geliştirme sınırları

Durum: Kabul edildi. Tarih: 2026-09-14.

Kaynak blueprint ve kullanıcının başlama talebi esas alınmıştır. React + Vite + TypeScript, Tailwind, TanStack Query; Hono + Cloudflare Workers; Supabase PostgreSQL; Zod; pnpm workspace; Vitest ve ilerleyen UI aşamasında Playwright kullanılacaktır.

Tek uygulama içinde tüm kodu toplamak başlangıçta kolay olsa da sunucu güvenlik sınırını belirsizleştirir. Ayrı depolar ise iki geliştirici arasında sözleşme senkronizasyonunu zorlaştırır. Bu yüzden blueprint monorepo yapısı korunur. Ortak paketler kaynak TypeScript sunar; Vite ve Wrangler bunları paketler. game-core herhangi bir runtime, ağ veya veritabanı bağımlılığı taşımaz.

1. adım yalnız altyapıdır. /health liveness bildirir; veritabanı veya üretim hazırlığı garantisi değildir. Kimlik doğrulama, ekonomi ve Telegram SDK sonraki adımlarda eklenir. İstemciye yalnız VITE_ önekli, herkese açık değerler verilir. Bot token ve Supabase service role anahtarı API ortamında kalır.

Geliştiriciler HANDOFF.md üzerinden sıradaki tek adımı alır. Kullanıcıya her adım sonunda kısa tamamlanma mesajı verilir ve çalışma durur. Kullanıcı Gemini'ye geçerse aynı dosyalar doğruluk kaynağıdır.
